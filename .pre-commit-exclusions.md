# Pre-Commit - Configuração de Exclusões

Este arquivo documenta como configurar exclusões de pastas/arquivos no pre-commit.

## 🎯 Quando Usar Exclusões

Você pode querer excluir pastas quando:
- Contém código gerado automaticamente (`.terraform/`, `node_modules/`)
- Contém dependências externas
- São arquivos que não devem ser validados (binários, imagens)
- São diretórios `.git/`, `.github/`

## 📋 Pastas Já Ignoradas

O projeto já ignora automaticamente:
- `.terraform/` - Cache do Terraform
- `.git/` - Diretório Git
- `node_modules/` - Dependências Node.js

## 🔧 Como Adicionar Exclusões

### Opção 1: Adicionar ao Hook Específico (Recomendado)

Editar `.pre-commit-config.yaml` e adicionar `exclude`:

```yaml
- repo: https://github.com/pre-commit/pre-commit-hooks
  hooks:
    - id: terraform_fmt
      exclude: |
        (?x)^(
          \.terraform/.*|
          \.git/.*|
          minha-pasta-customizada/.*|
          vendor/.*
        )$
```

### Opção 2: Adicionar Globalmente no Repositório

Criar arquivo `.pre-commitignore`:
```
.terraform/
.git/
vendor/
node_modules/
dist/
build/
```

### Opção 3: Usar .gitignore

Se a pasta está em `.gitignore`, pre-commit a ignora por padrão.

## 📝 Exemplos Práticos

### Exemplo 1: Ignorar Diretório Específico

```yaml
exclude: |
  (?x)^(
    meu-diretorio/.*
  )$
```

### Exemplo 2: Ignorar Múltiplos Diretórios

```yaml
exclude: |
  (?x)^(
    vendor/.*|
    node_modules/.*|
    build/.*|
    dist/.*
  )$
```

### Exemplo 3: Ignorar Arquivo Específico

```yaml
exclude: |
  (?x)^(
    meu-arquivo\.tf$
  )$
```

### Exemplo 4: Ignorar por Padrão de Nome

```yaml
exclude: |
  (?x)^(
    .*\.generated\.tf$|
    .*_auto\.yaml$
  )$
```

## 🔍 Sintaxe de Exclusão

O pre-commit usa **regex** para exclusões. Aqui estão os padrões comuns:

| Padrão | Significado |
|--------|-------------|
| `.*` | Qualquer coisa |
| `\.terraform/.*` | Tudo dentro de `.terraform/` |
| `\.git/.*` | Tudo dentro de `.git/` |
| `.*\.tf$` | Arquivos terminados em `.tf` |
| `meu-dir/.*` | Tudo dentro de `meu-dir/` |
| `(?x)` | Ativa modo "verbose" (permite comentários) |
| `\|` | OU lógico |
| `^` | Início da string |
| `$` | Final da string |

## 🎯 Caso de Uso: Excluir Pasta de Testes

Adicionar ao hook que deseja excluir:

```yaml
- id: terraform_validate
  exclude: |
    (?x)^(
      terraform/tests/.*|
      terraform/examples/.*
    )$
```

## 🚀 Exemplo Completo

```yaml
repos:
  - repo: https://github.com/pre-commit/pre-commit-hooks
    rev: v4.5.0
    hooks:
      - id: trailing-whitespace
        # Ignora arquivos gerados e diretórios específicos
        exclude: |
          (?x)^(
            \.terraform/.*|
            \.git/.*|
            terraform/examples/.*|
            node_modules/.*
          )$

      - id: end-of-file-fixer
        exclude: |
          (?x)^(
            \.terraform/.*|
            vendor/.*
          )$
```

## ⚙️ Pre-Commit Ignora Automaticamente

Por padrão, pre-commit já ignora:
- Arquivos em `.gitignore`
- Arquivos fora do repositório Git
- Submodules Git

## 🔧 Customização Avançada

### Ignorar por Tipo de Arquivo

```yaml
# Apenas validar arquivos .tf
files: ^terraform/.*\.tf$
exclude: ^terraform/examples/.*\.tf$
```

### Ignorar Múltiplos Padrões

```yaml
exclude: |
  (?x)^(
    # Diretórios
    \.terraform/.*|
    \.git/.*|
    node_modules/.*|
    vendor/.*|

    # Arquivos
    .*\.lock\.hcl$|
    .*\.state$|
    .*\.backup$
  )$
```

### Usar Apenas em Alguns Diretórios

```yaml
# Apenas em terraform/, ignora k8s/
files: ^terraform/.*\.tf$
```

## 📋 Checklist

Quando adicionar uma exclusão:

- [ ] Verificar se a pasta deve ser ignorada de verdade
- [ ] Usar regex correto na exclusão
- [ ] Testar com `pre-commit run --all-files`
- [ ] Documentar o motivo da exclusão

## 🚨 Cuidado

**Não ignore:**
- Arquivos de código que você escreveu
- Diretórios que precisam ser validados
- Arquivos que podem conter secrets (use `detect-secrets` em vez disso)

## 💡 Dicas

1. **Debug:** Rodando pre-commit em arquivo específico:
   ```bash
   pre-commit run terraform_fmt --files terraform/bootstrap/cluster/main.tf
   ```

2. **Ver o que vai ser processado:**
   ```bash
   pre-commit run --all-files --verbose
   ```

3. **Testar exclusão:**
   ```bash
   # Sem exclusão (pode falhar)
   pre-commit run --all-files

   # Com exclusão adicionada
   pre-commit run --all-files
   ```
